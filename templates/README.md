# ❤️ Heart Disease Prediction System

An AI-powered web application that predicts the possibility of heart disease using Machine Learning and Flask.

---

# 📌 Project Overview

This project uses a Machine Learning model trained on heart disease data to predict whether a person is at risk of heart disease based on medical parameters.

The application is built using:

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS

---

# 🚀 Features

✅ Heart Disease Prediction  
✅ Safe Probability Display  
✅ Beautiful Responsive UI  
✅ Machine Learning Integration  
✅ Flask Web Application  
✅ Random Forest Classifier  
✅ Real-Time Prediction  

---

# 🧠 Machine Learning Model

Algorithm Used:

- Random Forest Classifier

Accuracy Achieved:

- ~79% Accuracy
